# 🛡️ ScamShield

ScamShield is a simple web app that helps users check whether a call, message, or link looks suspicious.

## What it does

- 📞 **Call Checker** – asks simple Yes/No questions and gives a risk level.
- 💬 **Message Checker** – checks a message for common scam warning signs.
- 🔗 **Link Checker** – checks a link for suspicious patterns.

## Technologies

- HTML
- CSS
- JavaScript

## How it works

ScamShield looks for common warning signs and gives a result like:

🟢 Low Risk  
🟠 Suspicious  
🔴 High Risk

## Note

The result is only a risk estimate based on common warning signs. It does not guarantee that something is completely safe or a scam.
